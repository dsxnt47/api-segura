\# 🛡️ API RESTful Segura com Node.js, TypeScript &amp; JWT API RESTful desenvolvida com \*\*Node.js\*\*, \*\*Express\*\* e \*\*TypeScript\*\*, focada na implementação de práticas recomendadas de segurança defensiva e \*\*DevSecOps\*\* (alinhadas aos guias da OWASP e NIST). A aplicação conta com validação defensiva de dados de entrada, criptografia forte de senhas, autenticação por tokens JWT, autorização via middlewares e gerenciamento seguro de variáveis de ambiente. --- ## 🚀 Tecnologias Utilizadas \* \*\*Linguagem &amp; Ambiente:\*\* Node.js + TypeScript \* \*\*Framework Web:\*\* Express \* \*\*Validação de Schemas:\*\* [Zod](https://zod.dev/) \* \*\*Criptografia de Senhas:\*\* [bcryptjs](https://github.com/dcodeIO/bcrypt.js) \* \*\*Autenticação Stateless:\*\* [JSON Web Token (JWT)](https://jwt.io/) \* \*\*Gestão de Segredos:\*\* dotenv --- ## 🔒 Recursos de Segurança Implementados 1\. \*\*Validação Defensiva de Entrada (\`Zod\`):\*\* Valida e sanitiza o formato de e-mail e exige comprimento mínimo para senhas antes do processamento. 2\. \*\*Criptografia Forte de Senhas (\`bcrypt\`):\*\* Armazenamento seguro de hashes de senha com salt automático. 3\. \*\*Autenticação e Autorização (\`JWT\`):\*\* Emissão de tokens assinados com chave secreta e expiração programada (\`expiresIn: '1h'\`). 4\. \*\*Middleware de Proteção de Rotas:\*\* Intercepta e valida o cabeçalho HTTP \`Authorization: Bearer
